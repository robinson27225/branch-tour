From WikiTree, in this browser

Uses your WikiTree login. Public profiles only; living people are left out.

within of Needs internet. It checks which states or countries are in reach, then looks up only the places in those, about one a second. People whose place cannot be found are left out.
Or import files you already have

On WikiTree Plus, run your search (for example your CC7) and download it as Excel or Separated values. Plus only lists public profiles, which is what a tour can use; private ones are skipped. Drop the file here. You can also drop the JSON export from the Genealogy Report app, which adds biographies and burial places. Living people are left out.

To see how each person is related to you in one cemetery: open the cemetery category on WikiTree, press My Connections, and save that page (File, Save Page As) as .html. Press Next and save again for more. Drop all the pages together, and add your report JSON too if you like. A Plus search saved as JSON only lists profile IDs. Drop it first and it filters the table you drop next.

    Gemma in this browser

    About 1 to 2 GB, downloaded once from Hugging Face and kept by the browser. After that it writes stories with no signal and nothing leaves this device. Needs a browser with WebGPU, such as recent Chrome or Edge.

    Gemma with Ollama

    1. Install Ollama from ollama.com/download.
    2. Get Gemma:
    3. Start Ollama so this page may talk to it:
      If it says "address already in use", Ollama is already running (the Mac app starts it as soon as it is installed). Quit it from the menu bar icon and run the command again. Or, on a Mac, keep the app and run once, then quit and reopen the Ollama app. On Windows, set the OLLAMA_ORIGINS environment variable to this address and restart Ollama.

    The Ollama address has to be on the same computer as this browser. A phone cannot reach a laptop's Ollama from an https page, so on a phone choose Gemma in this browser. Safari blocks the connection to Ollama, so use Chrome, Edge or Firefox.
